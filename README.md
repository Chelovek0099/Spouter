# 🔊 Spouter

**Spouter** — это легкий и эффективный аналог Soundpad, построенный на стеке **WPF** и **NAudio**. Идеальное решение для тех, кто хочет быстро запускать звуковые эффекты в голосовые чаты без лишней нагрузки на систему.

---

## ✨ Основные функции

Первая версия (v1.0) сфокусирована на простоте и скорости:
*   **8 настраиваемых пэдов:** Быстрый доступ к вашим любимым звукам.
*   **Индивидуальная настройка:** Для каждого пэда можно задать:
    *   Путь к аудиофайлу.
    *   Уровень громкости.
    *   Глобальный хоткей (работает даже при свернутом окне).
*   **Чистый звук:** Использование библиотеки NAudio обеспечивает стабильную работу с аудиопотоками.

---

## 🛠 Настройка (Quick Start)

Чтобы звук из Spouter попадал в ваш микрофон (в Discord, Telegram, игры), используйте метод виртуального микширования:

1.  **Виртуальный кабель:** Установите виртуальное аудиоустройство (например, **VoiceMeeter** или **VB-CABLE**).
2.  **Вывод звука:** В настройках Spouter выберите виртуальный вход (Input) в качестве устройства воспроизведения.
3.  **Микширование:** В целевом приложении (например, Discord) выберите этот же виртуальный кабель как устройство ввода (микрофон).
4.  **Готово!** Теперь звуки пэдов будут транслироваться вместе с вашим голосом.

## 🗺 Roadmap (Планы по развитию)

Проект активно развивается. В ближайших планах:
- [ ] **Unlimited Pads:** Уход от жесткого ограничения в 8 слотов — создание динамических страниц или прокручиваемого списка.
- [ ] **MyInstants Integration:** Интеграция API [myinstants.com](https://www.myinstants.com) для быстрого поиска, предпрослушивания и добавления звуков прямо в приложении.
- [ ] **Встроенный драйвер:** Реализация собственного виртуального аудио-кабеля и функции прямого микширования микрофона внутри Spouter, чтобы исключить необходимость в стороннем ПО (VoiceMeeter).
